# Mantovani SYS

> **Sites, presença digital e soluções web para empresas.**

A **Mantovani SYS** é uma solução independente de desenvolvimento web criada para construir sites profissionais, presença digital e produtos digitais sob medida.

Este repositório contém o código-fonte do site institucional da Mantovani SYS.

---

## Visão geral

O projeto apresenta os serviços da Mantovani SYS e funciona como ponto central para contato, apresentação comercial e presença digital.

### O site inclui

- Landing page institucional responsiva
- Apresentação de serviços
- Seção de soluções e diferenciais
- Chamadas para contato via WhatsApp
- Informações comerciais
- SEO técnico e conteúdo para buscas
- Open Graph e Twitter Cards
- Dados estruturados Schema.org
- Sitemap XML
- robots.txt
- Favicon e Apple Touch Icon
- Manifest para experiência mobile
- Suporte multilíngue preparado para PT-BR, EN e ES
- Elementos de conversão e navegação
- Design responsivo para desktop e dispositivos móveis

---

## Serviços apresentados

O site estrutura a oferta da Mantovani SYS em três frentes principais:

| Serviço | Objetivo |
|---|---|
| **Sites Profissionais** | Criar uma presença web profissional, responsiva e orientada a conversão |
| **Presença no Google** | Melhorar a forma como uma empresa é encontrada e apresentada online |
| **Presença Digital** | Estruturar pontos de contato e soluções digitais para o negócio |

---

## Arquitetura do projeto

O projeto é uma aplicação web estática organizada de forma simples para facilitar manutenção e publicação.

```text
mantovanisys/
├── index.html       # Estrutura principal e SEO
├── style.css        # Identidade visual e responsividade
├── script.js        # Interações e comportamento
├── images/          # Imagens, favicon e recursos visuais
├── robots.txt       # Diretivas para mecanismos de busca
├── sitemap.xml      # Sitemap do site
└── CNAME            # Domínio personalizado
```

## Desenvolvimento local

Não há dependências de framework obrigatórias para executar a versão estática atual.

Abra o projeto em um servidor HTTP local para testar corretamente recursos como manifest, rotas e assets.

Exemplo:

```bash
git clone https://github.com/mantovanip/mantovanisys.git
cd mantovanisys
```

Depois, utilize qualquer servidor HTTP local de sua preferência.
